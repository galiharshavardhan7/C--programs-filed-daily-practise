# C program collection

Programs are arranged by the main concept they demonstrate:

- `arrays` — array creation, searching, sorting, and array exercises.
- `decision_making` — `if`/`else` and conditional-logic exercises.
- `loops_and_patterns` — iteration, number/star patterns, and control-flow examples.
- `number_programs` — numerical algorithms such as primes, factorials, Fibonacci, and palindrome checks.
- `functions_and_pointers` — functions, recursion, pointers, and pass-by-value examples.
- `basics_and_io` — introductory I/O, data types, conversions, and character examples.
- `miscellaneous` — small standalone exercises that do not fit a single topic.

All programs were retained. The executable formerly named `s` is in `miscellaneous/s_executable`.

Several programs have identical contents but have deliberately been retained, including the Fibonacci, power-of-two, prime-printing, reverse, square-pattern, X-pattern, perfect-number, Armstrong, power, and palindrome variants.
